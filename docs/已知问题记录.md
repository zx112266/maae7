### 2026-11-15 01:37 已修复｜欧勒毕斯指南：关完弹窗后断链 ✅

- **现象**：`guide_detect` 跑完记 `failed`，人停在指南面板；11-03、11-13 两次复现，11-15 第三次复现（task 200000011）。
- **根因（两层）**：
  1. `guide_detect.next` 把 `close_popup_guide_reward` 排在 `guide_click_claim` 前面，而那个「×点击关闭」`[590,682]` **本就是指指南面板自己的按钮**——每轮“开面板 → 弹窗清理器抢到 → 把面板关掉 → 回入口重开”，白转 3 次、22 秒；
  2. `guide_close_popup` 的 ROI `[590,509,102,41]`（y 509–550）看不到底部 y≈681 的按钮，父节点 2000 ms 预算耗尽 → `bad next` → 硬失败。
- **修法**：`guide_detect.next = ["guard_disconnect","guide_click_claim"]`（开面板直接领）；`close_popup_guide_reward.next` 复原为 `["guard_disconnect","guide_detect"]`、`max_hit` 3→2；`guide_close_popup` ROI 改 `[0,560,1280,160]` + `target:true`；`guide_close_reward_popup` `timeout` 2000→6000 并补 `on_error ["guide_close_popup","guide_click_exit"]`。
- **实测**：task 200000013 **38.5 s**、200000014 **24.7 s**，均 `succeeded` 并回大厅；残留约 6 s 空等（面板已关、第二层找不到），用户判定可接受。

### 优化｜秘密商店：刷新成本与每日限购

### 优化｜召唤：免费次数用「反向证明」判定

- 数字识别不可靠（`1,610` 会读成 `940`），改用「免费」字样判断；

- **只要弹出「进行召唤吗」确认框，就说明免费次数已用完** → 点「取消」退出，绝不点确认（脚本永远不会花钱）。

### 工具链｜MaaMCP 的三个坑（非脚本问题）

1. `run_pipeline` **不会覆盖同名节点**：改了 JSON 仍按旧定义跑，必须重启进程；
2. 杀掉 maa-mcp 进程后 DSH **不会自动重启**，MCP 工具全部超时；
3. 改用 `maafw-cli` 需手工把 `keys.txt` 补进 `...\maafw-cli\resource\model\ocr`，否则 `resource status` 报 `ocr_model: false`。
4. `stop_pipeline` 对正在跑的任务返回 `tasker_stopped:false`，任务会**继续点**；`clear_pipeline_resources()` 也停不掉。
