## 简介

这是一个基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 的《第七史诗》日常自动化项目。

通过图像识别驱动游戏界面，自动完成竞技场、讨伐、迷宫、骑士团、圣域、宠物小屋、签到、
召唤以及赛季周本等每日/每周重复操作。所有流程均为可视化识别，不读取、不修改游戏内存。

## 功能一览

| 任务 | 说明 |
| --- | --- |
| 启动游戏 | 拉起游戏、处理冷启动与网络重连、关闭活动弹窗、确认进入大厅 |
| 竞技场自动战斗 | 自动打竞技场，次数用完自动退出 |
| 讨伐地狱级快速战斗 | 地狱级快速战斗 |
| 迷宫商人购买强化石 | 走图到商人，购买强化石与誓约书签 |
| 骑士团世界首领战 | 每天 2 次，打完自动退回大厅 |
| 商店领取免费物资 | 领取每日免费商品 |
| 圣域精灵之森照料 | 浇水、种植、关怀 |
| 宠物小屋领养宠物 | 每日领养 |
| 欧勒毕斯指南领取奖励 | 指南任务奖励领取 |
| 关闭签到及各类弹窗 | 领取签到奖励，并清理各类弹窗 |
| 誓约召唤（免费优先） | 有免费次数时优先 10 连，需要消耗时自动取消 |
| 秘密商店购买誓约书签 | 进店查看商品，命中书签则购买；可选是否花天空石刷新 |
| 欧多马顿塔（赛季周本） | 自动爬塔，按装置品质择优，最多 25 层 |

## 使用方法

### 环境要求

- **安卓模拟器**（推荐 MuMu 12）或真机，通过 ADB 连接；亦支持桌面端窗口
- **分辨率**：脚本以 `1280 × 720` 为识别基准，其他分辨率会自动缩放
- **游戏语言**：简体中文（识别依赖界面文字）

### 使用步骤

1. 启动游戏并进入大厅
2. 运行发布包内的可执行文件（Windows 下为 `maae7.exe`）
3. 选择控制器「安卓端」，连接模拟器
4. 勾选需要执行的任务，点击开始
5. 首次使用建议先单独运行「启动游戏」，确认能正常进入大厅

> **说明**：战斗菜单会记住上次停留的标签页（一般 / 赛季）。
> 讨伐与迷宫会自动切回「一般」，欧多马顿塔会切到「赛季」，无需手动调整。

## 项目结构

```
assets/
  interface.json          任务、选项、控制器定义
  resource/
    pipeline/*.json       各副本的流程脚本
    image/                模板匹配用图片
    model/ocr/            OCR 模型
tools/
  install.py              打包脚本（含按项目名重命名可执行文件）
.github/workflows/        CI：打包、校验、发布
```

## 已知限制

- 依赖界面文字识别，游戏改版或更换语言后可能需要重新适配
- 部分 OCR 文本会被识别成近似字形，脚本已尽量用短片段匹配，但仍可能出现漏判
- 秘密商店刷新会消耗天空石，默认不刷新（需要手动选择次数才会刷）
- 高层欧多马顿塔单场战斗时间较长，属正常现象
